# Temporal Forge FSR-era claim/evidence ledger

**Closure date:** 2026-09-15  
**Standard:** [`EVALUATION_STANDARD.md`](EVALUATION_STANDARD.md)

This ledger summarizes the major claims that materially affected the FSR-centered Temporal Forge direction. It is an index, not a replacement for the underlying manifests, traces, reports, or code.

| Claim | Disposition | Evidence / qualification |
|---|---|---|
| Temporal inputs such as motion/history/jitter participate in the output. | **SUPPORTED WITH QUALIFICATION** | Multiple matched ablations in [`../../benchmarks/video_corpus/RESULTS.md`](../../benchmarks/video_corpus/RESULTS.md) changed spatial or temporal metrics when motion, history, jitter, or recurrent behavior changed. Participation does not imply that the tested surrogate is beneficial. |
| More accurate or more expensive motion estimation should materially improve FSR reconstruction from ordinary video. | **NOT SUPPORTED** | The completed 288-key multi-frame matrix in [`../../benchmarks/quality_sweeps/MOTION_CAMPAIGN.md`](../../benchmarks/quality_sweeps/MOTION_CAMPAIGN.md) found no repeatable quality gain from better motion. Zero motion was best or near-best at three source tiers; offline dense flow did not establish an upper-bound win and generally increased temporal-delta error. |
| Scalar motion-confidence thresholding is the dominant limiter. | **NOT SUPPORTED** | Motion-campaign confidence changes were generally very small; the controlled sweep proved the threshold changed admission behavior but did not establish it as the dominant quality bottleneck. |
| Source resolution/detail loss is a dominant factor in the available campaign. | **SUPPORTED** | Motion-campaign absolute SSIM fell sharply at 240p/360p while arm ordering did not turn into a better-motion win. This supports source-detail loss as a stronger observed effect than estimator sophistication in that matrix. |
| Synthetic jitter can affect reconstruction and should be treated as an explicit control. | **SUPPORTED WITH QUALIFICATION** | Jitter on/off and variable-jitter experiments changed measured results in scene-dependent ways. No universal jitter policy was proven. See [`../../benchmarks/video_corpus/RESULTS.md`](../../benchmarks/video_corpus/RESULTS.md) and archived M5/M6 records. |
| A raw adjacent-frame midpoint can substitute for the missing temporal sample. | **CONTRADICTED IN TESTED SCOPE** | Matched midpoint experiments lost spatial SSIM versus aligned controls; simple midpoint display was rejected for promotion. |
| Cheap block-motion compensation fixes the midpoint/interpolation path. | **CONTRADICTED IN TESTED SCOPE** | The motion-compensated midpoint probe remained below matched controls and did not recover the missing temporal benefit. |
| Better dense correspondence alone is enough to make simple midpoint synthesis competitive. | **CONTRADICTED IN TESTED SCOPE** | Dense future→current tiles improved the cheap probe slightly but still remained below the matched midpoint-input control. This does not reject a purpose-built dense-flow reconstruction architecture. |
| Increasing the internal reconstruction grid is universally beneficial. | **NOT SUPPORTED** | [`../reports/FSR4_SUPERSAMPLING_REPORT_20260831.md`](../reports/FSR4_SUPERSAMPLING_REPORT_20260831.md) found gains on some slices and losses on others with added memory cost. Reconstruction and delivery dimensions therefore remain separate controls; 3x was not promoted as a universal default. |
| The original current learned path was universally superior to strong spatial controls. | **NOT SUPPORTED** | M6 and corpus evidence contains scenes/resolutions where Lanczos or base-only spatial controls win spatial aggregate or temporal error. Conditional wins were preserved as conditional. |
| Quality Lab composition materially changes measured output. | **SUPPORTED** | The repository retains multiple composition and learned-strength controls; the shipped measured profile and experiments demonstrate that final composition policy materially affects quality and can dominate what the neural path contributes. |
| Automated metrics alone were sufficient to certify lattice safety. | **CONTRADICTED** | Human review reopened a prior automated PASS after visible periodic lattice corruption was observed. The affected campaign evidence was marked historical/invalidated and the diagnostic was reopened. See [`../LATTICE_CORRUPTION_DIAGNOSTIC.md`](../LATTICE_CORRUPTION_DIAGNOSTIC.md) and [`../reports/QUALITY_LAB_REVIEW_ADJUDICATION_20260906.md`](../reports/QUALITY_LAB_REVIEW_ADJUDICATION_20260906.md). |
| A valid FSR 4.1 experimental path was technically achievable on the target Linux/RDNA3 system. | **SUPPORTED WITH QUALIFICATION** | The repository contains a proof-gated native INT8 path, reconstructed dispatch/parameter contracts, runtime traces, clean-clone handling, fallback behavior, and retained provenance. This is an interoperability/research result, not a claim of parity with AMD's complete implementation. |
| The FSR 4.1 path is portable as a clean public repository without hidden maintainer dependencies. | **SUPPORTED WITH QUALIFICATION** | The 2026-09-09 portability campaign remediated path/dependency assumptions, completed three consecutive remediation-free clean loops, and received independent verification. Reverse-engineering-derived native pack data still carries explicit unresolved-rights/provenance status. |
| Finished video provides all semantic information expected by a game temporal upscaler. | **NOT SUPPORTED / KNOWN FALSE AS A GENERAL ASSUMPTION** | The project premise explicitly identifies missing renderer-side information: motion semantics, jitter, reset/history context, exposure, reactive/composition signals, depth/ownership-like information, and related contracts must be inferred, synthesized, or omitted. |
| Reconstructing/synthesizing enough expected FSR inputs is the strongest path to the project's broader objective. | **NOT SUPPORTED BY THE CUMULATIVE EVIDENCE** | Considerable effort improved correctness, provenance, and observability, but the quality campaign repeatedly found weak sensitivity to increasingly plausible motion, scene-dependent temporal behavior, and strong dependence on architecture/composition choices. The repository does not contain evidence sufficient to justify FSR-specific expected-input reconstruction as the next primary investment. |
| FSR 4.1 can never be useful for ordinary video. | **UNRESOLVED / NOT CLAIMED** | The experiments do not prove impossibility. Future work could discover stronger mappings, additional hidden semantics, better side inputs, or a different integration strategy. This closure deliberately does not make that claim. |
| Temporal information across ordinary video frames can contain source-supported detail useful for reconstruction. | **SUPPORTED AS A RESEARCH DIRECTION, NOT YET A CLOSED ARCHITECTURE** | Multi-frame video necessarily contains repeated and changing observations of persistent scene structure, and this repository showed measurable temporal participation. The successor project must independently determine the strongest reconstruction mechanism without presuming FSR, optical flow, ML, or a fixed temporal window. |
| Temporal Forge should continue with FSR 4.1 adaptation as its architectural center. | **PROJECT DECISION: CLOSED** | The cumulative evidence is sufficient to end that investment path. The successor starts from the reconstruction objective, not from FSR-specific assumptions. See [`FSR41_FINAL_ADJUDICATION_20260915.md`](FSR41_FINAL_ADJUDICATION_20260915.md). |

## Reading rule

A ledger disposition applies only to the tested scope identified by its evidence. Where the evidence is scene-, resolution-, hardware-, or configuration-specific, the conclusion remains correspondingly bounded.
